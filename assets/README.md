## 以后要换图

1. 直接把同名文件覆盖进这个目录即可，不需要改 HTML。
2. 手机截图建议：宽度压到 820px、JPEG 质量 84，单张控制在 200KB 以内。
3. 截图前请检查：真实 API Key、手机号、真实用户昵称、聊天里的隐私内容，务必打码或换成示例数据。
4. 想新增截图位：复制 `index.html` 里的 `<figure class="shot" data-src="assets/xxx.png" ...>` 整段，改文件名和图注即可。
