## 建议

- 截图请裁掉系统任务栏、浏览器书签栏等无关区域，只保留应用本身。
- 敏感信息（真实 API Key、手机号、真实用户昵称）务必打码或替换为示例数据。
- PNG 建议先用 [squoosh.app](https://squoosh.app/) 压到 200KB 以内，移动端加载更快。
- 命名保持全小写英文 + 短横线，避免中文文件名导致的 URL 编码问题。
