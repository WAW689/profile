## 以后要换图

1. 用同名文件覆盖即可，不需要改 HTML。
2. 手机截图建议：宽度 820px、JPEG 质量 84，单张 200KB 以内。
3. 截图前检查：API Key、手机号、真实用户昵称、聊天里的隐私内容，务必打码。
4. 新增图片位：复制页面里任意一段 `<figure class="shot">…</figure>`，改 `href` / `src` / `alt` / 图注即可。
